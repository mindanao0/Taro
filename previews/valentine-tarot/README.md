# Valentine Tarot — work in progress

A separate 78-card tarot deck in the Victorian rose style. All depicted human characters should be women, including traditionally male tarot roles. Five cards are present: The Fool, The Magician, The High Priestess, The Empress and The Lovers; 73 remain. This deck is distinct from the 22-card Valentine Oracle. Neither deck is integrated into the website yet.

The shared sample card back is at ../valentine-oracle/card-back.png.
