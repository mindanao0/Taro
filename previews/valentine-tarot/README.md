# Valentine Tarot — work in progress

A separate 78-card tarot deck in the Victorian rose style. The Lovers is the first preview. The other 77 cards have not been made. This deck is distinct from the 22-card Valentine Oracle; neither deck is integrated into the website yet.

Major Arcana: 22 cards. Minor Arcana: 56 cards across Wands, Cups, Swords, and Pentacles.

The shared sample card back is at ../valentine-oracle/card-back.png.
